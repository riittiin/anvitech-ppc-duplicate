    Efficiency report

    How much each operator produced in a month, compared with the standard time for those jobs. This is a report only. It never changes the plan.

    Attended (min) = time on shift minus recorded downtime and setup. Earned (min) = standard time credited for GOOD pieces only. Rejects earn nothing. Efficiency % = Earned ÷ Attended × 100. Pace vs standard (x) = how many times faster/slower than standard cycle time (1.0 = exactly standard, 1.2 = 20% faster). Reject % = rejected ÷ (good + rejected) qty. No-standard punches = entries for an item/process with no time standard on file. These are left out of both earned and attended time, so they never count against the operator.
